This project demonstrates how to perform edge detection on images using the OpenCV library in Python. The Canny Edge Detection algorithm is used to identify object boundaries and significant intensity changes within an image.

Workflow
  1. Import OpenCV library.
  2. Read the input image.
  3. Convert the image to grayscale.
  4. Apply the Canny Edge Detection algorithm.
  5. Display the original image and the detected edges.

Technologies Used
  - Python
  - OpenCV (cv2)
  - Google Colab
